# Façade plugin

**WIP — early prototype. Nothing to install yet.**

Thin agent integrations for Façade, a local photo editor.
Currently supports **Codex and Cursor on macOS**. Other hosts are on the roadmap.

There is no public DMG download or standalone plugin release yet.
